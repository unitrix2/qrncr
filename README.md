# QR Studio Pro

Design QR codes that look like your brand. Everything runs in the browser, so nothing you type is uploaded anywhere.

Built by **Salman**.

## Features

**Content types:** website, plain text, Wi-Fi, UPI payment, contact card (vCard), WhatsApp, email, phone call, SMS, calendar event, crypto payment, social profile.

**Design**
- Six data-dot styles, three eye-frame styles, two eye-center styles
- Solid or gradient dots (linear or radial), custom eye colors
- **Transparent background** (PNG, WebP and SVG keep the transparency; JPG and PDF are filled white)
- Center logo: ready-made badges or your own upload, with size and padding controls
- Frames: bottom banner, top banner, bubble, polaroid, phone, with your own label and colors
- Error correction L / M / Q / H
- 14 presets, light and dark theme, optional animated background

**Checks and tools**
- Live scan-safety check (contrast, inverted colors, logo size vs error correction)
- Scanner: camera or image upload, plus "Test current design" to verify your own code reads correctly
- Batch generator: one code per line, downloaded as a ZIP with an index CSV
- Save designs in the browser, export and import them as JSON

**Export:** PNG, SVG, PDF, JPG, WebP at 512 to 4000 px, or copy the image to the clipboard.

## Run locally

```bash
npm install
npm run dev        # development server
npm run build      # production build (writes dist/, docs/, root index.html and assets/)
npm run preview    # preview the build
```

Requires Node.js 18 or newer.

## Deploy

- **GitHub Pages (Actions):** push to `main`, then Settings → Pages → Source → *GitHub Actions*.
- **GitHub Pages (no build):** Settings → Pages → Deploy from a branch → `main` / `/docs`.
- **Vercel / Netlify:** import the repository. `vercel.json` and `netlify.toml` are included.

See `DEPLOYMENT_GUIDE.md` for a step-by-step walkthrough (Hindi + English).
